- **2026-06-09:** Waypoint framework initiated. Extracted from an established pattern used on a prior application project: a structured directory of OPORD, CONOPS, memory, feature docs, and skills that gave an AI assistant persistent project knowledge across sessions. The goal is to make that approach reusable and vendor-agnostic. Key decisions: full `.waypoint/` directory structure required (no minimum subset), CONOPS template structure is fixed and non-negotiable, OPORD is opinionated baseline that projects extend, three-phase workflow (ideation → planning → execution) retained, Waypoint is complementary to execution tools like Superpowers (no dependency, no knowledge of each other). Adapters are thin vendor-specific wiring; core is plain Markdown. CONOPS written and approved. OPORD, templates, skills, adapters, and README complete.
